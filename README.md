## Featured work

### MY Toppers Hub
**A student resource portal**

A learning-focused website designed to make academic resources easier to discover and navigate. It brings subject-wise notes, unit-based resources, search and subject aliases, and ways to request missing notes or share feedback into one place.

- **[Open live website](https://luv-malik.github.io/MY_Toppers_Hub/)**
- **[View source code](https://github.com/Luv-Malik/MY_Toppers_Hub)**

### CivicPulse
**Civic issue reporting and triage MVP**

A prototype for reporting civic issues such as potholes, water leaks, waste, and broken streetlights. It groups potentially duplicate reports using location distance and text similarity, then calculates a transparent heuristic priority score to support human review.

- **[Open live demo](https://civic-pulse-eta-gold.vercel.app)**
- **[View source code](https://github.com/Luv-Malik/Civic-Pulse)**
- **Stack:** Java 21, Spring Boot, React, PostgreSQL, Leaflet / OpenStreetMap

> CivicPulse is a hackathon/learning MVP, not an official municipal service. Its sample data and priority scores are illustrative and should not be treated as verified safety assessments.

## About this portfolio

The portfolio is built with **plain HTML, CSS, and JavaScript**—no framework or build step required. Its visual direction uses a deep-space palette, a subtle animated starfield, editorial typography, project cards, and a responsive layout.

Highlights:
- Responsive navigation and layouts for desktop and mobile
- Animated hero typography and a subtle starfield canvas
- About section with a personal profile image
- Featured project cards linking to live work
- Interactive, category-based skills section
- Dedicated “Connect with me” links for LinkedIn, LeetCode, and GitHub
- Keyboard focus states and reduced-motion support

## Run locally

```bash
git clone https://github.com/Luv-Malik/portfolio.git
cd portfolio
open index.html
```

If your system does not support the `open` command, open `index.html` directly in your browser.
