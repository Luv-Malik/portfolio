Problem-firstBUILDING APPROACH

How I approach a build

Find the friction

Understand what is confusing, slow, repetitive, or unnecessarily hard for the person using it.

Make the path clear

Give information a hierarchy and make the next useful action obvious.

Make it work, then make it better

Build in small steps, test the important paths, and improve what the product actually needs.
